## Input Compatibility

Handle different input types:

| Input Type | Approach |
|---|---|
| Polished scripts | Standard workflow directly |
| User-written rough text | Before the formal workflow, do a quick scriptsystematically organize — organize text into scene structure, annotate each scene's core events, then enter the formal workflow |
| Story outlines / synopses | Same as rough text — systematically organize first, then formal workflow |
| Existing work modification requests | Adjust within the relevant step rather than restarting |

If input is rough text or an outline, before starting, do one round of fast script systematically organize: organize the text into scene structure, annotate each scene's core events, then enter the formal workflow.
