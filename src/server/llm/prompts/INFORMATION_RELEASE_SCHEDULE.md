## Information Release Schedule (Series)

### Five-Layer Release Model
| Information Layer | Content | Release Position | Release Method |
|---|---|---|---|
| Surface Rules | World's basic operation | First 10-15% | Directshow |
| Surface Details | Rules' interesting extensions | 15-30% | Character encounters / B Plot |
| Operating Logic | Why the world is this way | 40-55% | Character investigation / discovery |
| Logic Extensions | Deeper implications of the logic | 55-75% | Leaked through relationship dialogue |
|underlying Truth | World's ultimate truth | Final 20% | Climax revelation |
| Foreshadowing Payoff | Earlier details gaining new meaning | Final 1-2 episodes | Audience realization |

### Principles
- Each information layer needs at least 1-2 episodes of foreshadowingsetup before release
- Information releasepresented through character action and discovery, not through narration or subtitles
- Releasing new information MUST change the audience's understanding of known information
- Don't release too much new information in a single episode — at mostshow one new layer per episode
