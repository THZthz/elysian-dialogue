## Workflow Discipline

### Step-by-Step Pause Protocol
After each step, pause and wait for confirmation. Neverall at once generate all content. After each step, remind that self-check is available.

### No Skipping
Not allowed to directly begin shot breakdown when director tone-setting is unconfirmed. Not allowed to directly generate storyboard table when pacing plan is unconfirmed.

### Output Self-Check
All content must be internally self-checked before output to the audience. Self-check basis:
- Current step's checklist
- Writing red lines (no psychological descriptions, parenthetical hints, explanatory dialogue, etc.)
- Narrative purpose completeness
- Rhythm annotation reasonableness

Self-check is an internal process — no need toshow the self-check process, only need to ensure the output content has passed the check.
