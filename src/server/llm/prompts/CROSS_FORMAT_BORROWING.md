## Cross-Format Technique Borrowing

Different formats' techniques are not isolated. A good storyteller takes a concept short's reversal logic and uses it in a feature's cold open; takes McKee's value shift and uses it to test every scene of a short.

### From Concept Shorts
- **High-concept reversal** → use in any format's single scene. Core capability: "use one reversal to redefine all preceding information." Can shrink to single-scene scale.
- **Concept purity test** → test any format's logline. If your feature can't be stated clearly in one sentence, the core concept isn't sharp enough yet.
- **Zero-explanation pure-visualestablishment** → use in any format needing rapid rule establishment. Don't explain rules; directly show consequences through images.
- **Concept combination methods** → use in any format's conception phase. Five combination methods aren't just for ultra-shorts — when a feature or series feels "not sharp enough," use these methods to re-collision.
- **Multi-structure types** → shrink to a sequence/single scene in features/series.
- **AV language arsenal** → use in any format's visually impactful sections. Split screen, jump cut montage, picture-sound misalignment, silence, fixed-frame timelapse, mockumentary/pseudo-documentary, color restriction — in features and series, these typically only appear in specific sections.

### From Shorts
- **Information density montage** → use in feature's Fun and Games section, series time-advancement sections.
- **Single-variableextreme limitextrapolation** → use in feature climax sequence or series bottle episode.
- **Zero-degree expression** ("the greater the disaster, the flatter the tone") → use in any format's highest-emotion moment.

### From Features
- **McKee value shift** → test any format's every scene. "Is the core value at scene end different from scene start?" This validation criteria isn't limited to McKee-system features.
- **Ghost/Lie/Flaw chain** → simplified for short character design. If a short character feels "too flat," borrow Ghost/Lie/Flaw thinking — no need for fullunfold, justhints at: there's an unspoken reason behind the character's behavior. One detail is enough.
- **Foreshadowing / payoff** → shrink to short scale. A short has only a few minutes, but aexquisite foreshadowing-payoff within that short time hasinstead greaterimpactpower — because the audience still remembers the foreshadowing.
- **Subplot mapping logic** → simplified for short's secondary characters. If a short has a secondary character, let that character walk the path the protagonist "didn't take."

### From Series
- **Episode-end hook logic** → use in feature's sequence transitions. Each sequence ending leaves a "small hook" — an unanswered question, anunease detail.
- **Arc budget thinking** → use in feature's pseudo-change planning. Treat arc as a limited resource, allocate to different sections.
- **Information release schedule** → use in feature's world-building management.
- **Continuity tracking thinking** → use in feature's third-act writing.

### How to Use This Map
1. Don'tforcefully borrow. Only consult when facing a specific problem.
2. What's borrowed is the thinking method, not the format.
3. Especially useful during the script doctor phase — when something feels "off" but you can't name what, diagnose with another format's validation criteria.
