## McKee Story Principles

Suitable for: dramas with high character complexity, theme-first works, stories requiring deep dramatic tension. Core logic: story is "the transformation of values" — every scene must cause some life value (love/hate, freedom/bondage, truth/lie, etc.) to undergo an irreversible positive/negative flip. A scene without value transformation is a wasted scene.

### Controlling Idea
The entire work expressed as a one-sentence thematic judgment. Format: [Value] + [Cause]. For example: "Justice prevails because the protagonist is willing to sacrifice everything they cherish." For example: "Love collapses before utilitarianism because the calculating instinct within human nature will ultimately corrode sincerity." The Controlling Idea determines the ending — it is the final conclusion the entire work argues for.

### Value Charge
Every scene has a core value (life/death, love/hate, hope/despair, etc.). At the scene's start, this value is in some state (positive or negative). By the scene's end, a flip must occur (positive→negative, or negative→positive). If a scene's value state at the end is the same as at the start — delete this scene.

### The Gap
When a character takes action, there is a gap between the expected result and the actual result. This gap deepens — each time the character thinks they've learned, the next gap is deeper and more unexpected than the last.

### Inciting Incident
An event that completely shatters the balance of the character's life. Can be causal (result of the character's actions) or coincidental (caused by external forces). The Inciting Incident creates the story's core question — which cannot be answered before the ending.

### Progressive Complications
Conflict must escalate step by step. Each failed attempt must cost more than the last. McKee's key requirement: you cannot only escalate external difficulties — the character's internal predicament must deepen synchronously. "If your character faces the same level of difficulty at minute 60 as at minute 30, your story has stalled."

### Crisis Choice
The character faces an irreversible dilemma:
- The lesser of two evils (choose the least bad option)
- Irreconcilable goods (must choose only one of two valuable things)
  This choice must be a genuine dilemma — both options carry weight. If one option is clearly better, it's not a true crisis.

### Climax
The crisis choice made actionable. The character makes the choice and bears the consequences. The climax must be irreversible — after making this choice, neither the character nor the world can return to the state before the climax.

### Resolution
The new order after the climax. Briefly show the changed world. The Controlling Idea receives its final confirmation or refutation here.
