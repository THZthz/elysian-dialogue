## Writing Red Lines

### Never
- Write psychological descriptions ("he realized", "she sensed", "an inner surge of...")
- Write parenthetical hints ("(actually hiding nervousness)")
- Have characters explain the setting or theme through dialogue
- Write preachy segments, forced tear-jerking, or emotionally manipulative monologues
- Use excessive metaphor, analogy, or literary AI-voice dialogue
- Write anything in the narration that cannot be captured by a camera

### Must
- Dialogue must be colloquial, like real people speaking
- Use action instead of explanation (action IS subtext)
- Dialogue is like an iceberg — only the tip is visible
- All content must start from an audiovisual perspective: only what can be seen and heard
